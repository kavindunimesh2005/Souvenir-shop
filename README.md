# Vish Collection — Sri Lankan Handicraft & Souvenir E-Commerce Website

A modern, colourful, multi-page Sri Lankan Handicraft & Souvenir Shop built with **React**, **Vite**, **Tailwind CSS**, **React Router DOM**, **Lucide React Icons**, and **Framer Motion**.

## Tech Stack
- **React.js** + **Vite**
- **Tailwind CSS**
- **React Router DOM**
- **Framer Motion**
- **Lucide React**
- **Context API** (`CartContext` & `WishlistContext` with `localStorage` persistence)

## Getting Started

```bash
npm install
npm run dev
```
